# AssurEasy

## 🛡️ About AssurEasy

AssurEasy is a modern web-based insurance platform designed to make insurance services simple, accessible, and easy to understand.

The platform helps users discover insurance services, understand different types of insurance coverage, and access important information through a simple and user-friendly interface. ok 1

## 🎯 Project Objective

The main objective of AssurEasy is to simplify the insurance experience by creating a digital platform where users can easily:

- Learn about insurance
- Explore available insurance services
- Understand insurance coverage
- Get information about insurance plans
- Contact the insurance service
- Navigate through insurance information easily

## ✨ Features

- Modern and professional user interface
- Responsive design
- Home page
- Insurance services section
- About section
- Contact section
- Insurance information
- Easy navigation
- Mobile-friendly layout
- Interactive elements
- Clear and simple presentation of insurance services

## 💻 Technologies Used

The project is built using the following technologies:

- HTML5
- CSS3
- JavaScript
- Python
- Flask
